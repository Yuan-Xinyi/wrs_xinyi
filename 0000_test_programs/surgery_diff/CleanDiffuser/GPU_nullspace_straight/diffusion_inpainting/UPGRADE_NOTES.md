## 🎨 可视化逻辑

### 颜色编码

| 颜色 | 含义 | 示例 |
|------|------|------|
| 🟢 绿色 | 真实（Ground Truth） | 最不透明 |
| 🔴 红色 | 预测1（最确定） | α=0.6 |
| 🟠 橙色 | 预测2（较确定） | α=0.52 |
| 🟡 黄色 | 预测N（最不确定） | α=0.2 |

### 透明度意义

- **不透明** (α=0.9)：真实值，要求准确性最高
- **较透明** (α=0.6)：预测开始，置信度高  
- **半透明** (α=0.4)：中间预测，置信度中等
- **最透明** (α=0.2)：最后预测，用来展示多样性

### 理解可视化

#### 情况1：优秀模型 ✓

```
所有彩色机器人紧密堆积在绿色机器人周围
↓
预测很稳定，都聚集在真实值附近
↓
✓ 模型优秀，可以部署
```

#### 情况2：中等模型 ⚠️

```
彩色机器人聚集但有一定分散
↓
预测稳定性不够，but接近真实值
↓
⚠️ 可以使用但需要监控
```

#### 情况3：系统偏差 ⚠️

```
彩色机器人聚集很紧，但离绿色机器人远
↓
预测一致但有系统错误
↓
⚠️ 需要调整（学习率、数据、network）
```

#### 情况4：预测不稳定 ❌

```
彩色机器人分散开来
↓
预测不稳定，多样性太高
↓
❌ 需要更多训练或数据清理
```

## 🔧 技术改进

### 批量机器人创建

```python
# 创建多个Franka机器人实例
for pred_idx, q_pred in enumerate(q_preds):
    robot = FrankaResearch3()
    robot.fk("arm", np.asarray(q_pred))
    meshmodel = robot.gen_meshmodel(rgb=color, alpha=alpha)
    meshmodel.attach_to(base)
```

优势：
- ✓ 每个预测独立可视化
- ✓ 支持不同的透明度表达不同含义
- ✓ 易于扩展为排序或着色方案

### 容错处理

```python
try:
    robot.fk("arm", np.asarray(q_pred))
except Exception as e:
    print(f"⚠️  FK失败: {e}")
    continue  # 使用默认配置继续
```

- ✓ FK错误不会导致整个脚本崩溃
- ✓ 问题可视化日志清晰
- ✓ 部分失败不影响其他预测

### FK性能优化

当前实现：
```python
# 逐个计算FK
for q_pred in q_preds:
    robot.fk("arm", q_pred)  # N次调用
```

未来优化（FK_batch）：
```python
# 批量计算FK（如果WRS支持）
all_configs = np.vstack([q_true, q_preds])  # (N+1, 7)
results = robot.fk_batch(all_configs)       # 一次调用
```
